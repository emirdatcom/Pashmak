# بریف آرت (برای تصویرگر؛ پرامپت 22)

**ممنوع:** رفرنس مستقیم، ردکشی یا استخراج از اپ مرجع؛ استفاده از نام‌های مرجع. فقط «سبک» و «تناسبات» توضیح‌شده‌ی زیر.

## سبک
وکتور تخت، بدون خط دور، سایه‌ی نرم یک‌تن‌تیره‌تر، تناسب گرد و تپل، چشم نقطه‌ای مشکی، گونه‌ی صورتی محو.

## گربه
کوچه‌ای با ته‌مایه‌ی پرشین، نارنجی-کرم، لکه‌ی قهوه‌ای روی یک چشم، گردنبند فیروزه‌ای. سر بزرگ، تنه‌ی گرد کوچک، دم ضخیم گرد. رنگ‌های خز: نارنجی-کرم (پیش‌فرض)، خاکستری دودی، سه‌رنگ.
- مراحل: `kitten` (سر نسبت به تنه بزرگ‌تر)، `young`، `adult`. هر مرحله از لایه‌های جدا: بدن، سر، چشم، دم، گوش + لایه‌ی اکسسوری.
- حالت‌ها: `happy, sleepy, sad, proud, curious, breathing` (چشم بسته، فقط صورت)، `away`.
- اسلات اکسسوری: `collar, hat, glasses, scarf` (+ پس‌زمینه). هر اکسسوری برای هر ۳ مرحله لنگر جدا دارد.

## صحنه‌ها (۴ لایه: آسمان، دوردست، میانه، زمین؛ ۳ زمان روز)
حیاط حوض‌دار (پیش‌فرض)، پشت‌بوم غروب، کوچه با درخت توت. فرمت WebP یا SVG؛ حجم هر صحنه ≤ ۱۵۰KB.

## فهرست اسلات‌ها و ابعاد
| دسته | ابعاد | فرمت |

| گربه (۳ مرحله × ۷ حالت) | ۵۱۲×۵۱۲ | SVG/WebP شفاف |
| اکسسوری لباس (۱۶+ آیتم) | ۲۵۶×۲۵۶ | WebP شفاف |
| وسایل خونه (۱۶+ آیتم) | ۲۵۶×۲۵۶ | WebP شفاف |

| فروشنده‌ی اورجینال (`{SHOPKEEPER_NAME}`: جوجه‌تیغی یا کلاغ بازاری با کلاه نمدی؛ نه جغد) | ۵۱۲×۵۱۲ | SVG |
