# چک‌لیست بررسی روی دستگاه (برای مالک محصول)

هدف: مقایسه‌ی چشمی هر صفحه با مرجع و ثبت مشکل. سه دستگاه مرجع (سند ۸۰ §۶): ۱) گوشی ۲GB RAM با Android 8، ۲) Xiaomi (MIUI)، ۳) Samsung با Android 13+.

## آماده‌سازی
```
cd app
flutter run --flavor bazaar -t lib/main_bazaar.dart --dart-define=DEMO_SEED=true     # یا --flavor myket / lib/main_myket.dart
```
`DEMO_SEED` سکه (۳۰۲)، اهداف، ماجراجویی آماده، کشفیات و مأموریت‌ها را پر می‌کند. فقط در debug/profile کار می‌کند؛ در release غیرفعال است. برای اسکرین‌شات خودکار (با emulator یا دستگاه وصل‌شده):
```
flutter test integration_test/screenshots_test.dart --flavor bazaar -d <device> --dart-define=DEMO_SEED=true
```
خروجی: `docs/visual-diff/device/`. (در محیط ساخت اجرا نشد.)
